# 🖥️ Arachne 电脑终端

一个基于 **ApricityUI (AUI)** 制作的 Minecraft **Win95 风格电脑终端** 界面。

在游戏内放置「电脑终端」方块并右键,即可打开一个完整的 Win95 桌面系统——文件管理器、工作台、文档、软盘读取一应俱全,还带有 **CRT / VHS 复古显示效果** 与 **黑屏演出**。

> 整个界面完全用 HTML / CSS / JS 在游戏内渲染,无需任何外部浏览器或插件。

---

## ✨ 功能特性

### 🖥️ Win95 桌面
- 桌面图标:我的电脑 / 工作台 / 文档(单击选中、双击打开)
- 开始菜单:点击左下角「开始」按钮开/关
- 底部任务栏:窗口按钮(点击最小化/恢复)、游戏内时间时钟

### 📂 文件管理器(我的电脑)
- 本地磁盘 (C:) / 控制面板 / 打印机 / **读取软盘**
- 侧边栏树切换面板,窗口标题与图标同步变化

### 🛠️ 工作台
- 「车票转化.exe」:双击触发合成,`4× 未知碎片 + 1× 车票 → 真车票`
- 内置 3×3 合成台 GUI(摆放材料、点击输出格合成)

### 📁 文档
- 一号 ~ 四号车厢文件夹

### 💾 Arachne 软盘系统
- 史诗稀有度物品「**Arachne 软盘**」
- 「我的电脑 → 读取软盘」:10 秒读取进度条(检测 → 已检测到 → 正在读取,中段随机停顿)
- 读取成功:全屏**黑屏演出**,逐段显示对话文本,黑屏期间隐藏鼠标
- 背包中没有软盘时:弹窗提示

### 📺 CRT / VHS 显示效果
- **CRT**:屏幕暗角、扫描线横纹、动态噪点
- **VHS**:每 50~70 秒随机触发信号闪烁、撕裂线、画面抖动
- 像素字体:英文使用 98.css 同款 *Pixel Sans*,中文使用 *Fusion Pixel*

### 🪟 多窗口管理
- 窗口自由拖拽、标题栏最小化/恢复、点击置顶
- 任务栏图标随窗口与面板切换同步
- 打开/关闭瞬间自动修复 AUI 文本渲染问题(无闪烁)

## 📦 前置依赖

| 模组 | 版本 | 说明 |
|---|---|---|
| Minecraft Forge | 1.20.1 | 游戏本体加载器 |
| KubeJS (Forge) | 2001.6.5+ | 脚本框架(物品/方块/网络事件) |
| Rhino | 2001.2.3+ | KubeJS 的 JS 引擎依赖 |
| ApricityUI (AUI) | 1.2.0 | HTML GUI 渲染核心 |
| Architectury API | 9.x | AUI 的跨平台依赖 |

> 实测运行版本:ApricityUI `1.2.0` + KubeJS `2001.6.5-build.26`

---

## 📥 安装

1. 安装 **Forge 1.20.1** 及上表全部前置模组
2. 将仓库中的 `kubejs/` 文件夹复制到游戏版本目录下:
   `.minecraft/versions/<你的版本>/kubejs/`
3. 将 `apricity/` 文件夹复制到同目录下:
   `.minecraft/versions/<你的版本>/apricity/`
4. 启动游戏即可

---

## 🎮 游戏内使用

1. 获取电脑终端方块:`/give @s kubejs:computer`,放置后**右键**打开桌面
2. 获取 Arachne 软盘:`/give @s kubejs:arachne`,放入背包
3. 双击桌面「我的电脑」→ 双击「读取软盘」体验完整读取流程

## 📁 文件结构

```
kubejs/                  # KubeJS 脚本与资源(游戏逻辑)
├── startup_scripts/     #   物品/方块注册(Arachne 软盘、电脑终端)
├── server_scripts/      #   服务端逻辑(开屏、合成、软盘检测、时间同步)
├── client_scripts/      #   客户端桥接层(HTML ↔ 服务端通信)
├── assets/              #   模型 / 贴图 / 语言文件
└── config/

apricity/                # AUI 前端界面(游戏内 GUI)
└── computer/
    ├── gui.html         #   桌面结构 + Win95 样式
    ├── gui.js           #   全部界面逻辑(窗口 / 软盘 / VHS / 黑屏…)
    ├── fonts/           #   像素字体(英文 + 中文)
    └── icons/           #   Win95 风格图标
```

## ⚠️ 说明

- 本项目为个人制作,仅供学习交流使用
- GUI 依赖 ApricityUI 的 HTML 渲染能力,不同 AUI 版本间显示效果可能存在细微差异
- 界面逻辑对 AUI 的一些已知限制做了兼容处理(如 `el.style` 无效、`setInterval` 不可靠、`@font-face` 仅支持 ttf/otf 等)
