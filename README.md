# Arachne 电脑终端

一个基于 **ApricityUI (AUI)** 制作的 Minecraft **Win95 风格电脑终端** 界面。
放置「电脑终端」方块并右键,即可在游戏内打开一个复古的 Win95 桌面系统。

> 整个界面用 HTML / CSS / JS 在游戏内渲染,无需外部浏览器。

---

## 功能

### 桌面效果
- 完整的 Win95 风格桌面:桌面图标(单击选中 / 双击打开)、开始菜单、底部任务栏
- 任务栏显示游戏内时间时钟,窗口图标实时同步

### 文件管理器
- 「我的电脑」窗口:本地磁盘、控制面板、打印机等经典条目
- 侧边栏树切换面板,窗口标题与图标联动

### 显示效果
- **CRT**:屏幕暗角、扫描线横纹、动态噪点
- **VHS**:每 50~70 秒随机触发信号闪烁、撕裂线、画面抖动
- 像素字体:英文 98.css 同款 *Pixel Sans* + 中文 *Fusion Pixel*

### 多窗口管理
- 窗口自由拖拽、标题栏最小化 / 恢复、点击置顶
- 任务栏窗口按钮切换,打开 / 关闭无文本闪烁
